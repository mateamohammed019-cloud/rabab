# رباب 🎀

هدية خاصة — تطبيق بسيط وجميل مزوّد بالحب، يعرض صورًا وموسيقى ومطر قلوب متساقط.

## المميزات

- 💗 **مطر قلوب** متساقط باستمرار في الخلفية
- 🖼️ **كاروسيل صور** يتقلب تلقائيًا بلا نهاية (يمين → يسار) ويمكن سحبه باليد
- 🎵 **مشغّل موسيقى** بقائمة أغاني أنيقة + إيكولايزر متحرك + تشغيل في الخلفية
- 💓 **قلب نابض** يتدرج لونه من الوردي إلى الأحمر + اسم "رباب" بخط رقعة مزخرف
- 📱 **أيقونة كرتونية** بأسلوب سناب شات (أفاتار + حلقة ملونة)

## التشغيل

```bash
flutter run
```

## إضافة صور أو أغاني

- الصور: ضعها في `assets/images/` وأضف أسماءها في `lib/photos.dart`
- الأغاني: ضع ملفات mp3 في `assets/audio/` وأضفها في `lib/songs.dart`

## بناء نسخة آيفون

اعمل نسخة من هذا المستودع على خدمة بناء سحابية (مثل Codemagic أو GitHub Actions) لإنشاء ملف iOS بدون ماك.
